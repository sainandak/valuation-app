Jewellery Valuation (React + Vite PWA)
Run:    npm install  then  npm run dev      (open the address on phone or computer)
Build:  npm run build  -> upload the dist folder to any static host (Netlify, Vercel, GitHub Pages)
Install on phone: open the hosted link, then "Add to Home screen".
Data is saved on the device (localStorage). Use Settings > Download backup regularly.
